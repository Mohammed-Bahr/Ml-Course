What is Machine Learning?

Machine Learning (ML) is the science and art of programming computers so they can learn from data. Unlike traditional computer programming, where a programmer writes explicit rules for a machine to follow (Command > Action), machine learning involves feeding data into an algorithm to build a statistical model that produces an output (Data > Model > Action). This allows computers to learn how to perform tasks without being explicitly programmed for every scenario.

ML Highlights

The Hierarchy of Machine Learning

To understand where ML fits, it is helpful to look at its lineage within computer science:

  • Computer Science: The broadest field, encompassing everything related to the design and use of computers.
  • Data Science: A narrower field focusing on extracting knowledge and insights from data using computers.
  • Artificial Intelligence (AI): The capability of machines to perform cognitive tasks that usually require human intelligence, such as perception or reasoning.
  • Machine Learning: A subfield of AI that uses self-learning algorithms to detect patterns and improve performance based on empirical information.

Problems Machine Learning Solves :

Machine Learning is particularly effective for several types of challenges:

  • Complex Problems: It is used for tasks where traditional approaches are too complex or have no known algorithmic solution, such as speech recognition, image classification, and natural language processing.
  • High-Maintenance Systems: It replaces long lists of hand-tuned rules that are dif
  • ficult to maintain. For example, a traditional spam filter requires constant manual updates, whereas an ML filter automatically learns new patterns.
  • Fluctuating Environments: ML systems can adapt to new data on the fly, making them ideal for changing conditions like stock market prediction.
  • Data Mining: It helps humans gain insights by discovering hidden patterns in massive datasets.
  • Simulating Human Cognition: ML enables machines to perform tasks once thought exclusive to humans, such as driving automobiles or beating world champions at games like Go.

Types of Machine Learning Systems

Machine Learning systems are generally classified into four broad categories based on how they are trained:

  1. Supervised Learning: The algorithm is fed labeled training data, which means the input data includes the desired solutions, called labels. Common tasks include classification (e.g., flagging emails as "spam" or "ham") and regression (e.g., predicting the price of a car based on its features).
  2. Unsupervised Learning: The training data is unlabeled, and the system tries to learn patterns without a teacher. Key tasks include clustering (grouping similar visitors to a blog) and dimensionality reduction (simplifying data without losing too much information).
  3. Semisupervised Learning: This approach uses a small amount of labeled data combined with a large amount of unlabeled data, often seen in photo-hosting services that recognize the same person across multiple untagged photos.
  4. Reinforcement Learning: A learning system, called an agent, observes an environment, selects actions, and receives rewards or penalties in return. It learns the best strategy, called a policy, to maximize rewards over time, which is how systems like AlphaGo beat world champions.

The Machine Learning Process

A typical project follows a structured workflow:

  • Data Scrubbing: This is the process of refining a dataset by removing irrelevant information, handling missing values, and converting text into numerical values (such as through one-hot encoding).
  • Training and Testing: You must never test your model on the same data used to train it. Typically, data is split into a training set (usually 70-80%) and a test set (20-30%). The model learns from the training set, and you use the test set to estimate the generalization error.
  • Cross-Validation: To maximize the use of available data, you can use k-fold validation, which splits the data into "buckets" and rotates which one is used for testing while training on the others.

Main Challenges for Beginners

Two primary things can go wrong in ML: "bad algorithm" and "bad data".

  • Data Issues: The model may fail if there is an insufficient quantity of data, if the data is nonrepresentative (sampling bias), or if it is filled with irrelevant features.
  • Overfitting: This occurs when a model is too complex and follows the training data's noise rather than the underlying patterns. It performs great on training data but poorly on new data.
  • Underfitting: This happens when a model is too simple to learn the data's structure, such as trying to fit a straight line to curved data.
  • Bias/Variance Trade-off: Bias is the error due to wrong assumptions (leading to underfitting), while variance is the error due to excessive sensitivity to small fluctuations in the data (leading to overfitting).

Common Algorithms to Know

  • Linear Regression: Finds the best straight line (hyperplane) to describe a relationship between variables.
  • Logistic Regression: Used for classification; it estimates the probability that an instance belongs to a certain class.
  • k-Nearest Neighbors (k-NN): A simple "voting" system where a new data point is classified based on which existing groups are closest to it.
  • Decision Trees: Powerful models that use a visual flowchart of rules to make decisions.
  • Neural Networks (Deep Learning): Inspired by the human brain, these use layers of interconnected nodes to solve highly complex problems like image and speech recognition.

Supervised vs Unsupervised Learning :

In machine learning, systems are primarily categorized by the amount and type of supervision they receive during training. The two most prominent categories are supervised and unsupervised learning.

Supervised Learning

In supervised learning, the training data fed to the algorithm includes the desired solutions, known as labels. The goal is for the algorithm to learn the relationship between input features (variables) and known outcomes so it can predict outcomes for new, unseen data.

  • Classification: Assigning instances to discrete classes, such as flagging an email as "spam" or "ham". (discrete categories)
  • Regression: Predicting a target numeric value, such as estimating the price of a car or a house based on its features. (continuous values)

Common Supervised Algorithms:

  • k-Nearest Neighbors (-NN): A simple algorithm that classifies new data points based on their proximity to existing labeled data pointssimilar to a "voting system" or "popularity contest" among the nearest neighbors.
  • Linear Regression: Fits a straight trendline (hyperplane) to a dataset to describe relationships and predict values.
  • Logistic Regression: Used for classification; it employs the sigmoid function to estimate the probability that an instance belongs to a specific class.
  • Support Vector Machines (SVM): A versatile model that separates classes by finding the widest possible "street" (margin) between them, making it robust against anomalies.
  • Decision Trees & Random Forests: Decision Trees use a flowchart-like structure to reach conclusions. Random Forests improve accuracy by combining the predictions of multiple trees, a technique known as ensemble learning.
  • Neural Networks: Inspired by the human brain, these process data through layers of interconnected "nodes" to solve highly complex patterns.

Unsupervised Learning

In unsupervised learning, the training data is unlabeled. The system attempts to learn patterns and uncover hidden structures within the data without the guidance of a "teacher" or known correct answers.

Primary Tasks:

  • Clustering: Identifying and grouping similar instances together, such as segmenting blog visitors into groups based on their interests.
  • Dimensionality Reduction: Simplifying data by merging correlated features into one (e.g., merging a car's age and mileage into a "wear and tear" feature) to improve performance and save space.
  • Visualization: Reducing complex, high-dimensional data to a 2D or 3D representation that can be easily plotted to identify patterns.
  • Anomaly Detection: Learning "normal" instances so the system can flag outliers, such as detecting fraudulent credit card transactions.
  • Association Rule Learning: Discovering interesting relationships between attributes, such as finding that people who buy barbecue sauce also tend to buy steak.

Common Unsupervised Algorithms:

  • -Means: A popular clustering algorithm that divides data into discrete, non-overlapping groups based on similar features.
  • Principal Component Analysis (PCA): The most popular dimensionality reduction algorithm, which identifies the hyperplane that preserves the maximum variance in the data.
  • -Distributed Stochastic Neighbor Embedding-SNE): ( Primarily used for visualization to keep similar instances close together in a low-dimensional space.
  • Apriori & Eclat: Algorithms specifically used for association rule learning.
  • Autoencoders: Neural networks designed to learn efficient, compressed representations (codings) of input data without supervision.
