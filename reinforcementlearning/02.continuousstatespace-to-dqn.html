1. Continuous State Spaces

Earlier RL examples (like a simplified Mars rover) used discrete states the agent could only be in one of a small number of positions (e.g., state ∈ {1, 2, 3, 4, 5, 6}).

Most real control problems are continuous state MDPs: the state is a vector of real numbers, each of which can take on any value in a range.

Examples of state vectors: ( for state)

System State vector Size
Rover on a line position ∈ [0, 6] km (any real value) 1

5. Exploration: Epsilon-Greedy Policy

Problem: while still learning, is a poor estimate. If you always pick (fully greedy/exploitation), and happens (due to bad random initialization) to think some action is always bad, the agent will never try that action and can never learn otherwise.

the agent never fires the main engine never sees it work never corrects its wrong belief. Its own preconception becomes self-fulfilling.

Solution Epsilon-greedy policy:

  • With probability (e.g., 0.95): pick (takes the greedy action called exploitation step).
    • Exploitation: use what you know to maximize return.
  • With probability (e.g., 0.05): pick a random action (take a random action called an exploration step).
    • Exploration: step gather experience about actions you've under-sampled.

This is called "epsilon-greedy" policy even though it's greedy most of the time the name refers to the exploration fraction , historically.

Common trick: start with high (e.g., , fully random) and gradually decay it (e.g., down to ) as learning progresses lots of exploration early, mostly exploitation once is reliable.
