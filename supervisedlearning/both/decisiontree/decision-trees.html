Decision trees are powerful supervised learning algorithms frequently used in competitive machine learning to handle classification and regression tasks.
They construct a predictive model by recursively partitioning a dataset based on feature values.
Tree Structural Anatomy : so it is basiclly binary tree.

  • Root Node: The top-most node where the dataset enters and the initial feature split occurs.
  • Decision Nodes: Internal evaluation nodes that test specific categorical or numeric features (e.g., ear shape or whiskers) to split data across branches.
  • Leaf Nodes: Terminal nodes at the bottom of the tree that deliver final target predictions (e.g., "Cat" vs. "Not Cat").
A decision tree is a flowchart for making predictions. You start at the root, ask a yes/no-style question about a feature (e.g. "is the ear shape pointy?"), follow the branch that matches your example, and keep asking questions until you land on a leaf node that gives you the answer (cat / not cat, or a number for regression).

The hard part isn't using a tree it's building one: deciding which feature to ask about at each node, and when to stop asking.

Recursive Tree Construction Process

  1. Root Feature Selection: Pick an initial feature to split all training samples across candidate branches.
  2. Sub-Branch Partitioning: Divide the dataset according to feature values and evaluate candidate splits on each resulting sub-branch.
  3. Iterative Splitting: Repeat the feature evaluation and partitioning process recursively on each child node.

Core Engineering Decisions

Decision Area Operational Strategy & Purpose
Splitting Criteria Select features that maximize sub-node label purity (isolating single classes) by minimizing metrics like entropy.
Stopping Criteria Halt splitting to prevent over-fitting and limit tree size:
• Node reaches 100% purity.
• Tree reaches a preset maximum depth limit (number of hops from the root).
• Purity gain falls below a minimum performance threshold.
• Sample size in a node falls below a minimum sample threshold.
Although decision trees rely on a composite set of historical heuristics(الاستدلالات الاستكشافية), their ability to split high-dimensional data into highly pure subsets makes them one of the most effective nonlinear models in practical machine learning.

Step 1: Measuring "Purity" with Entropy

Before you can decide what to split on, you need a way to measure how "mixed up" a group of examples is.

Intuition: A group that's all cats (or all dogs) is pure easy to predict. A group that's 50% cats / 50% dogs is maximally impure a coin flip.


Entropy: is a statistical metric that measures the amount of randomness, disorder, or impurity in a dataset.

  • Zero Entropy (0): The dataset is completely pure. All items belong to the same class (e.g., 100% yes or 100% no), meaning there is zero uncertainty.
  • Maximum Entropy (1 for binary data): The dataset is completely mixed and random. For example, an even 50/50 split between two classes represents maximum

(Entropy) captures this, where = fraction of positive examples (cats):

  • (50/50 mix) → (max impurity)
  • or (all one class) → (pure)
import numpy as np
def entropy(p1):
    if p1 == 0 or p1 == 1:
        return 0  # a pure set has zero impurity
    return -p1 * np.log2(p1) - (1 - p1) * np.log2(1 - p1)

Step 2: Choosing a Split Information Gain

At each node, you try splitting on every available feature and see which split reduces entropy the most.

That reduction is called information gain.

Formula:

  • : impurity before splitting.
  • : fraction of examples that go left/right (bigger groups matter more).
  • The subtracted term is the weighted average impurity after the split.

Intuition: "How much purer do my two groups become, weighted by their size, compared to before I split?" Bigger gain = better split.

You compute this for every candidate feature (ear shape, face shape, whiskers) and pick the one with the highest gain.

def information_gain(y, y_left, y_right):
    p_root = np.mean(y)
    w_left = len(y_left) / len(y)
    w_right = len(y_right) / len(y)
    p_left = np.mean(y_left) if len(y_left) else 0
    p_right = np.mean(y_right) if len(y_right) else 0
    weighted_entropy = w_left * entropy(p_left) + w_right * entropy(p_right)
    return entropy(p_root) - weighted_entropy

y = labels (1 = cat, 0 = not cat) at the current node; y_left/y_right are the labels after a candidate split.

Step 3: Building the Full Tree (Recursion)

The overall algorithm:

  1. Start with all examples at the root.
  2. Compute information gain for every feature; split on the one with the highest gain.
  3. Send examples left/right based on that feature's value.
  4. Repeat the same process independently on the left subset and the right subset each becomes a mini "root node" of its own sub-tree.
  5. Stop splitting a branch (make it a leaf) when:
    • the node is 100% pure (entropy = 0), or
    • you exceeding the maximum depth, or
    • the best information gain is below some threshold, or
    • the node has too few examples.

This is recursive: building a tree = building smaller trees on subsets, over and over again.

def build_tree(X, y, features, depth=0, max_depth=3):
    # Stopping conditions
    if entropy(np.mean(y)) == 0 or depth == max_depth or len(features) == 0:
        prediction = 1 if np.mean(y) >= 0.5 else 0
        return {"leaf": True, "prediction": prediction}

    # Pick the best feature
    best_feature, best_gain = None, -1
    for f in features:
        left_mask = X[f] == 1
        gain = information_gain(y, y[left_mask], y[~left_mask])
        if gain > best_gain:
            best_feature, best_gain = f, gain

    if best_gain <= 0:  # no useful split found
        prediction = 1 if np.mean(y) >= 0.5 else 0
        return {"leaf": True, "prediction": prediction}

    left_mask = X[best_feature] == 1
    remaining = [f for f in features if f != best_feature]
    return {
        "leaf": False,
        "feature": best_feature,
        "left": build_tree(X[left_mask], y[left_mask], remaining, depth + 1, max_depth),
        "right": build_tree(X[~left_mask], y[~left_mask], remaining, depth + 1, max_depth),
    }

The function calls itself (build_tree(...) inside build_tree) that's the recursion doing the "split, then split the pieces" logic.

Step 4: Handling Features with More than 2 Values One-Hot Encoding

So far every feature was binary (pointy/floppy). If a feature has categories (e.g. ear shape = pointy/floppy/oval), replace it with new binary features, each 0/1, exactly one of which is "hot" (1) per example:

ear = pointy ear = floppy ear = oval

0 0 1

This turns any categorical feature back into the simple binary case the algorithm already knows how to handle and it's the same trick used to feed categorical data into neural networks or logistic regression.

Step 5: Handling Continuous Features (like weight)

For a numeric feature (e.g. weight in pounds), you can't split into fixed categories. Instead:

  1. Sort all examples by that feature's value.
  2. Try splitting at the midpoint between every pair of consecutive values (threshold : "weight ≤ ?").
  3. Compute information gain for each threshold, same formula as before.
  4. Pick the threshold that gives the highest information gain, and compare it against other features as usual.
Intuition: you're just testing many possible "cut points" on a number line and keeping the best one.
def best_threshold(x, y):
    thresholds = np.unique((np.sort(x)[:-1] + np.sort(x)[1:]) / 2)  # midpoints
    best_t, best_gain = None, -1
    for t in thresholds:
        left_mask = x <= t
        gain = information_gain(y, y[left_mask], y[~left_mask])
        if gain > best_gain:
            best_t, best_gain = t, gain
    return best_t, best_gain

Step 6: Regression Trees Predicting a Number

If instead of "cat or not" you want to predict a number (e.g. animal weight), the idea is almost identical, but swap entropy for variance:

Intuition: variance measures how spread out the numbers are. A good split groups similar numbers together (low variance within each group).
  • Leaf node prediction = average of the target values that land there.
  • Pick the feature/split that gives the largest reduction in variance, same recursive process as classification.
def variance_reduction(y, y_left, y_right):
    w_left = len(y_left) / len(y)
    w_right = len(y_right) / len(y)
    return np.var(y) - (w_left * np.var(y_left) + w_right * np.var(y_right))

The whole algorithm boils down to one repeated question: "Which split makes my groups as pure (or as low-variance) as possible?" asked recursively, feature by feature, node by node, until you run out of useful splits.=~

def weighted_entropy(X,y,left_indices,right_indices):
    """
    This function takes the splitted dataset, the indices we chose to split and returns the weighted entropy.
    """
    w_left = len(left_indices)/len(X)
    w_right = len(right_indices)/len(X)
    p_left = sum(y[left_indices])/len(left_indices)
    p_right = sum(y[right_indices])/len(right_indices)
    
    weighted_entropy = w_left * entropy(p_left) + w_right * entropy(p_right)
    return weighted_entropy

def information_gain(X, y, left_indices, right_indices):
    """
    Here, X has the elements in the node and y is theirs respectives classes
    """
    p_node = sum(y)/len(y)
    h_node = entropy(p_node)
    w_entropy = weighted_entropy(X,y,left_indices,right_indices)
    return h_node - w_entropy
