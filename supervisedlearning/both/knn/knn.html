K‑Nearest Neighbor (KNN) is supervised algorithm a simple and widely used machine learning technique for classification and regression tasks.

It works by identifying the K closest data points to a given input and making predictions based on the majority class or average value of those neighbors.

The Core Idea: When a new, unknown data point arrives, the algorithm measures how "similar" (or close) this new point is to every single point in the training data.
It then looks at the K closest points (the K nearest neighbors) and makes a decision based on the majority of them.

  • For Classification: It assigns the new point to the class that appears most frequently among those K neighbors. This is called Majority Voting.
  • For Regression: Instead of voting for a class, it takes the average of the values of those K neighbors. This average becomes the predicted value for the new point.
Key Intuition: The algorithm assumes that similar things exist close to each other in the feature space. If a point is surrounded by points from Class A, it probably belongs to Class A.

Three Critical Properties of KNN

  1. Supervised Learning

    • KNN is a supervised algorithm. This means your training data must be labeled. You must know the correct class (or value) for every training sample. Without labels, KNN cannot work.

  2. Lazy Learner: KNN is called a "Lazy Learner" algorithm. This is very different from Neural Networks or other models.

    • Normal Models (eager learners): They have a separate, explicit training phase. They learn patterns from the training data, save parameters/weights, and then use those saved parameters to make fast predictions.
    • KNN (lazy learner): There is NO real training phase. The algorithm simply stores the entire training dataset. When a test sample arrives, it performs all the actual computation (distance calculations, sorting, voting) at that exact moment.

    Why this matters: The "training" is just memorizing data. All the hard work happens during testing.

  3. Non-Parametric Algorithm: This means it does not try to find an equation or a set of parameters (like weights w and bias b in a linear model) to separate the data.

    • In Linear Discriminant Functions, you search for a line equation (Ax + By + C = 0) where A, B, and C are parameters.
    • In KNN, there are no such parameters. The model is literally the data itself. It makes zero assumptions about the underlying data distribution. Whether your data is linearly separable, non-linearly separable, or comes from any strange distribution, KNN can still be applied.

Choosing the Value of k in KNN

The value of k determines how many nearest neighbors the algorithm considers before making a prediction. Picking the right k has a big impact on model performance, since it controls the trade-off between overfitting and underfitting.

  • Small k (e.g., k=1): The model is sensitive to noise and outliers, since a single unusual point can flip the prediction. This leads to overfitting high variance, low bias.
  • Large k: Predictions become smoother and more stable, since they're averaged over many neighbors. But if k is too large, the model may ignore local patterns and become too simplistic. This leads to underfitting high bias, low variance.

So the goal is to find a k that balances these two extremes for the dataset at hand.

Methods for Selecting k

1. Cross-Validation: Split the dataset into folds (unrelated to the KNN k unfortunate naming overlap). Train on folds and test on the remaining fold, repeating so every fold is used as the test set once. Do this for several candidate values of k, and pick the one with the best average validation accuracy (or lowest error).

2. Elbow Method: Plot error rate (or accuracy) against different values of k. Error typically drops sharply as k increases from 1, then flattens out. The "elbow" the point where the curve bends and additional increases in k stop giving meaningful improvement is a good candidate for the optimal k.

3. Use an Odd Value of k: For classification tasks (especially binary classification), choosing an odd k avoids ties when votes among neighbors are split evenly between classes.

Distance Metrics Used in KNN

KNN relies entirely on a distance metric to determine "nearness," so the choice of metric matters as much as the choice of k. Here are the main ones:

1. Euclidean Distance

The most commonly used metric straight-line ("as the crow flies") distance between two points. Best for continuous, similarly-scaled features.

# 1. Euclidean Distance
def euclidean_distance(x, y):
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    return np.sqrt(np.sum((x - y) ** 2))

2. Manhattan Distance (City Block / Taxicab)

Sum of absolute differences along each dimension like navigating a grid of city blocks.Less sensitive to outliers than Euclidean; useful in high-dimensional spaces.

# 2. Manhattan Distance
def manhattan_distance(x, y):
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    return np.sum(np.abs(x - y))

3. Minkowski Distance

A generalized form that includes both Euclidean and Manhattan as special cases, controlled by a parameter .

  • → Manhattan distance
  • → Euclidean distance
  • → Chebyshev distance
# 3. Minkowski Distance
def minkowski_distance(x, y, p=2):
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    if np.isinf(p):
        return np.max(np.abs(x - y))
    return np.sum(np.abs(x - y) ** p) ** (1.0 / p)

4. Chebyshev Distance

The maximum absolute difference across any single dimension like a king's move in chess. Useful when the worst-case (largest single) deviation matters most.

# 4. Chebyshev Distance
def chebyshev_distance(x, y):
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    return np.max(np.abs(x - y))

5. Hamming Distance

Counts the number of positions where two vectors differ. Used for categorical or binary data (not continuous). 𝟙

# 5. Hamming Distance
# Returns count of differing positions. Use np.mean(...) for fraction.
def hamming_distance(x, y):
    x = np.asarray(x)
    y = np.asarray(y)
    return np.sum(x != y)

6. Cosine Distance

Measures the angle between two vectors rather than their magnitude common in text/NLP and high-dimensional sparse data. 

# 6. Cosine Distance
def cosine_distance(x, y):
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    norm_x = np.linalg.norm(x)
    norm_y = np.linalg.norm(y)
    if norm_x == 0 or norm_y == 0:
        # Undefined for one zero vector; commonly treated as distance 1.
        return 0.0 if norm_x == 0 and norm_y == 0 else 1.0
    cosine_similarity = np.dot(x, y) / (norm_x * norm_y)
    return 1.0 - cosine_similarity

7. Jaccard Distance

Compares set overlap used for binary/categorical or set-based data (e.g., presence/absence features).

# 7. Jaccard Distance
# For binary/presence-absence vectors.
def jaccard_distance_binary(x, y):
    x = np.asarray(x).astype(bool)
    y = np.asarray(y).astype(bool)
    intersection = np.logical_and(x, y).sum()
    union = np.logical_or(x, y).sum()
    if union == 0:
        return 0.0
    return 1.0 - intersection / union

8. Mahalanobis Distance

Accounts for correlations between features and scales by the covariance matrix useful when features aren't independent or have different variances. where is the covariance matrix of the dataset.

# 8. Mahalanobis Distance
def mahalanobis_distance(x, y, S):
    """
    x, y: 1-D feature vectors
    S: covariance matrix of the dataset, shape (n_features, n_features)
    """
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    diff = x - y
    # Use pinv if S may be singular.
    S_inv = np.linalg.inv(S)
    # S_inv = np.linalg.pinv(S)
    return float(np.sqrt(diff.T @ S_inv @ diff))

Feature scaling (standardization/normalization) matters a lot for distance-based metrics like Euclidean and Manhattan, since features with larger numeric ranges can dominate the distance calculation.

How the KNN Algorithm Works Step by Step

KNN works on a simple idea: similar data points tend to be close to each other. To predict a new point, it looks at the labels or values of the K closest points in the training data and bases its prediction on them.

Step 1: Choose the Value of K

K is the number of nearest neighbors the algorithm will consider. A well-chosen K balances noise sensitivity against oversimplification (see previous discussion on choosing k).

Step 2: Calculate Distance

The algorithm computes the distance between the new (target) point and every point in the training dataset most commonly using Euclidean distance, though other metrics (Manhattan, Cosine, etc.) can be used depending on the data.

Step 3: Identify the Nearest Neighbors

The K training points with the smallest distances to the target point are selected as its "nearest neighbors."

Step 4: Make a Prediction

  • Classification → Majority voting: The algorithm checks which class is most common among the K neighbors and assigns that class to the new point.
  • Regression → Averaging: Instead of voting, the algorithm takes the average of the K neighbors' values and uses it as the prediction.

Example

Suppose K = 5. For a new test point, the algorithm finds the 5 closest data points in the training set. If most of those 5 neighbors belong to the grey class, the test point is classified as grey even if the point moves, the same rule reapplies, finding whichever 5 points are now nearest and re-voting.

Applications (Where KNN is Used)

🎬 Recommendation Systems (Netflix, Amazon)
Finds people whose tastes match yours, then recommends what they liked.

You liked Movie A and B. People who liked those also loved Movie C → "Recommended for you!"

📧 Spam Detection
Compares a new email to emails already marked spam or not spam.

If it looks like the junk mail your neighbors received, it probably is junk.

🛒 Customer Segmentation
Groups shoppers with similar buying habits together.

People who buy diapers also often buy baby formula → they belong in the same "young parents" group.

🎙️ Speech Recognition
Compares your voice sounds to sound patterns it already knows.

The sound you just made is closest to the known sound of the word "hello" → it types "hello."

Advantages (Why KNN is Liked)

✅ Simple to use No complicated math to understand. It's just "find similar examples and copy their answer."

✅ No training step It's like an open-book exam. It doesn't study in advance; it just looks things up when a question comes.

✅ Few settings to tune You only decide two things: how many neighbors to ask (k) and how to measure "closeness" (distance).

✅ Works for two types of problems:

  • Classification: "Is this email spam? → Yes/No" (majority vote)
  • Regression: "How much is this house worth? → $250,000" (average of neighbors' prices)

Disadvantages (Where KNN Struggles)

❌ Slow with big data Every prediction means comparing against all stored examples.

Imagine asking all 100,000 people in a stadium before making one decision.

❌ Struggles with many features Comparing people on 2 traits is easy. Comparing them on 1,000 traits? "Similarity" becomes meaningless noise.

❌ Can overfit If k = 1, you're trusting a single neighbor, who might just be an oddball. Small k = too sensitive to weird data points.

One weird neighbor says the restaurant is bad, so you never try it.

❌ Curse of dimensionality In high-dimensional data, everything ends up far away from everything else, so "nearest neighbor" stops meaning anything useful.

```python import numpy as np import matplotlib.pyplot as plt from collections import Counter

---------- Euclidean Distance ----------

def euclidean_distance(p, q):
p = np.array(p)
q = np.array(q)
return np.sqrt(np.sum((p - q) ** 2))

---------- KNN Classifier ----------

class KNearestNeighbors:
def init(self, k=3):
self.k = k
self.points = None

def fit(self, points): # as it is just lazy learner: just memorize the training set
    self.points = points

def predict(self, new_point):
    distances = []
    for category in self.points:
        for point in self.points[category]:
            distance = euclidean_distance(point, new_point)
            distances.append([distance, category])

    categories = [category[1] for category in sorted(distances)[:self.k]]
    result = Counter(categories).most_common(1)[0][0]
    return result

---------- 2D Example ----------

break
