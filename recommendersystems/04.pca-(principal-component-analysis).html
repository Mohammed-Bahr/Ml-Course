1. Why PCA? The Core Idea

Primary Use Case Today: Data visualization. By reducing 50 features down to 2, you can plot the data on a standard 2D scatter plot to identify clusters, patterns, or anomalies.

PCA is an unsupervised algorithm: there are only features and no label .
It takes data with many features (10, 50, thousands) and finds a small number of new axes that keep as much information as possible. With 2 or 3 axes you can plot the data.

Each new axis is a combination of the original features.
It lies within the same feature space and is not a new physical dimension.

The car examples (building the intuition)

Example Features What PCA does Why
1 length, width Essentially keeps length Width barely varies (road-lane constraint, about 1.8 m), so it carries little information
2 length, wheel diameter Essentially keeps length Wheel diameter varies little
3 length, height Finds a new diagonal axis Both vary, and they're correlated (big cars are longer and taller). The axis roughly means "size of the car"

Principle: information lives in variation. A feature (or direction) where all points look the same tells you nothing, so it's safe to drop.

PCA axes aren't automatically meaningful. Labels like "size" come from inspecting which original features contribute most to each axis (pca.components_, shown later).

Why bother visualizing? Plotting a new dataset helps you understand it and can reveal that "something funny is going on", suc h as outliers or errors.

2. How PCA Works

Step 0: Preprocessing

  1. Mean-normalize: subtract each feature's mean so the data is centered at the origin.
  2. Feature-scale if features have very different ranges (for example house size in thousands vs. bedrooms in single digits, or GDP in trillions vs. features under 100). Otherwise the large-scale feature dominates the variance and therefore dominates the axes PCA picks.

Step 1: Choose the axis that keeps the most variance

Given centered data, pick a direction (the -axis) and project every point onto it.

4. Implementation with scikit-learn

The four steps

Step Action Method
1 Scale features if ranges differ a lot StandardScaler (optional but often important)
2 Fit PCA to get the new axes pca.fit(X)
3 Check how much variance each axis explains pca.explained_variance_ratio_
4 Project the data onto the axes pca.transform(X)

Note: fit mean-normalizes automatically (it subtracts each feature's mean), so you don't need to do that yourself. It does not rescale features, so scaling is still your job.

Example: 2D to 1D

import numpy as np
from sklearn.decomposition import PCA

# The 6-example dataset from the course lab (reproduced from the lab, not from the transcript)
X = np.array([[ 1,  1],
              [ 2,  1],
              [ 3,  2],
              [-1, -1],
              [-2, -1],
              [-3, -2]])

pca_1 = PCA(n_components=1)      # keep ONE principal component
pca_1.fit(X)

print(pca_1.explained_variance_ratio_)   # [0.992]
X_trans_1 = pca_1.transform(X)           # shape (6, 1)
print(X_trans_1)                         # first row ≈ 1.383
  • explained_variance_ratio_ = 0.992: one axis retains 99.2% of the variability, so almost nothing is lost by using 1 number instead of 2.
  • The first example projects to , its distance from the origin along the axis.
  • The output has 6 numbers, one per training example.

(In the video this is called a "function", but it is actually an attribute, so it has a trailing underscore and no parentheses.)

A realistic workflow (high-dimensional data)

from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

X_scaled = StandardScaler().fit_transform(X_countries)   # e.g., 50 features per country

pca = PCA(n_components=2)
Z = pca.fit_transform(X_scaled)          # fit + transform in one call

print(pca.explained_variance_ratio_)     # how much info do 2 axes keep?
plt.scatter(Z[:, 0], Z[:, 1])            # plot z1 vs z2

PCA from scratch (to connect the math to the library)

def pca_scratch(X, k):
    mu = X.mean(axis=0)
    Xc = X - mu                              # mean normalization (what fit() does)
    C = Xc.T @ Xc / (len(X) - 1)             # covariance matrix
    vals, vecs = np.linalg.eigh(C)           # eigen-decomposition (ascending order)
    order = np.argsort(vals)[::-1]           # sort by variance, largest first
    vals, vecs = vals[order], vecs[:, order]
    W = vecs[:, :k]                          # top-k principal axes (unit, perpendicular)
    Z = Xc @ W                               # projection: z = w · x
    ratio = vals[:k] / vals.sum()            # explained variance ratio
    return Z, W, mu, ratio

Z, W, mu, ratio = pca_scratch(X.astype(float), 1)
X_recon = Z @ W.T + mu                       # reconstruction: z * w (+ mean)

On the lab dataset this gives the same 99.2% ratio and the same values. The signs of the axes may be flipped compared with scikit-learn, which is normal, because and span the same axis.

5. When to Use PCA (Ng's Advice)

Use Status per the video
Visualization (reduce to 2 or 3 dimensions and plot) Most common use today. This is what Ng uses it for
Data compression (for example 50 car features to 10, so 1/5 the storage or bandwidth) Used to be common. Rare now because storage and networks are much better
Speeding up supervised learning (for example 1,000 features to 100 before an SVM) Used to help older algorithms. With modern methods like deep learning it doesn't help much, and PCA has its own compute cost. Mostly seen in older papers

Practical tip (my addition): to choose the number of components when you're not just plotting, look at the cumulative explained variance, np.cumsum(pca.explained_variance_ratio_), and pick the smallest that reaches a target such as 95%.

Pitfalls to remember:

  • Scale your features first. Otherwise the largest-scale feature dominates the axes.
  • fit centers the data but doesn't scale it.
  • explained_variance_ratio_ is an attribute with a trailing underscore, not a method.
  • Axis signs can flip between runs or libraries.
  • Reconstruction from fewer than components is approximate, and the discarded variance is the error.
  • PCA is not regression. Don't use it to predict a target.
