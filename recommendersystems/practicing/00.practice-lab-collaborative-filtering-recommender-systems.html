2 - Recommender Systems

In this lab, you will implement the collaborative filtering learning algorithm and apply it to a dataset of movie ratings.

The goal is to learn three things:

  1. A parameter vector for each user, representing that user’s movie preferences.
  2. A feature vector for each movie, representing the movie in the same feature space.
  3. A bias for each user, representing whether that user usually rates higher or lower.

The dot product of a user vector and a movie vector, plus the user bias, estimates the user’s rating:

The diagram below details how these vectors are learned:

Existing ratings are stored in matrices. Y contains ratings from 0.5 to 5; a zero means no rating was recorded. R contains 1 where a rating exists and 0 otherwise. Movies are rows and users are columns. The user and movie vectors are learned together from the ratings that already exist.

One training example is shown above:

The same movie vector must work for all users who rated that movie, and the same user vector must work for all movies rated by that user. This shared learning is the reason for the name collaborative filtering.

Once the feature vectors and parameters are learned, they can be used to predict how a user might rate an unrated movie. This is shown in the diagram above. The equation is an example of predicting a rating for user one on movie zero.

In this exercise, you will implement cofiCostFunc, which calculates the collaborative filtering cost. Then you will use a TensorFlow custom training loop to learn X, W, and b.

def cofi_cost_func(X, W, b, Y, R, lambda_):
    """
    Returns the cost for collaborative filtering
    Args:
      X (ndarray (num_movies,num_features)): matrix of item features
      W (ndarray (num_users,num_features)) : matrix of user parameters
      b (ndarray (1, num_users)            : vector of user parameters
      Y (ndarray (num_movies,num_users)    : matrix of user ratings of movies
      R (ndarray (num_movies,num_users)    : matrix, where R(i, j) = 1 if the i-th movies was rated by the j-th user
      lambda_ (float): regularization parameter
    Returns:
      J (float) : Cost
    """
    nm, nu = Y.shape
    J = 0
    ### START CODE HERE ###  
    for j in range(nu):
        w = W[j, :]
        b_j = b[0, j]
        for i in range(nm):
            x = X[i, :]
            y = Y[i, j]
            r = R[i, j]
            J += np.square(r * (np.dot(w, x) + b_j - y))
    J = J / 2
    J += (lambda_ / 2) * (np.sum(np.square(W)) + np.sum(np.square(X)))
    ### END CODE HERE ###

    return J

Vectorized Implementation

The cost function will be called many times during optimization, so a vectorized version is faster than nested Python loops. The implementation below uses TensorFlow matrix operations.

tf.linalg.matmul(X, tf.transpose(W)) computes all movie-user dot products at once. Adding b gives predictions, subtracting Y gives errors, and multiplying by R removes missing ratings.

Run the code below and verify that it produces the same results as the non-vectorized version:

def cofi_cost_func_v(X, W, b, Y, R, lambda_):
    """
    Returns the cost for collaborative filtering
    Vectorized for speed. Uses tensorflow operations to be compatible with custom training loop.
    Args:
      X (ndarray (num_movies,num_features)): matrix of item features
      W (ndarray (num_users,num_features)) : matrix of user parameters
      b (ndarray (1, num_users)            : vector of user parameters
      Y (ndarray (num_movies,num_users)    : matrix of user ratings of movies
      R (ndarray (num_movies,num_users)    : matrix, where R(i, j) = 1 if the i-th movies was rated by the j-th user
      lambda_ (float): regularization parameter
    Returns:
      J (float) : Cost
    """
    j = (tf.linalg.matmul(X, tf.transpose(W)) + b - Y) * R
    J = 0.5 * tf.reduce_sum(j**2) + (lambda_ / 2) * (tf.reduce_sum(X**2) + tf.reduce_sum(W**2))
    return J

Training will learn the parameters , , and .

Because X, W, and b are learned together and do not form standard neural-network layers, use a custom training loop instead of the usual Keras Model, compile(), fit(), and predict() flow.

Each gradient-descent iteration does this:

  • Compute the cost (forward pass).
  • Compute the derivatives of the cost with respect to the parameters.
  • Update the parameters using the learning rate and gradients.

tf.GradientTape() records operations on TensorFlow variables. tape.gradient() calculates the gradients of the cost with respect to X, W, and b, and the optimizer applies those gradients.

iterations = 200
lambda_ = 1
for iter in range(iterations):
    # Use TensorFlow’s GradientTape
    # to record the operations used to compute the cost 
    with tf.GradientTape() as tape:

        # Compute the cost (forward pass included in cost)
        cost_value = cofi_cost_func_v(X, W, b, Ynorm, R, lambda_)

    # Use the gradient tape to automatically retrieve
    # the gradients of the trainable variables with respect to the loss
    grads = tape.gradient(cost_value, [X, W, b])

    # Run one step of gradient descent by updating
    # the value of the variables to minimize the loss.
    optimizer.apply_gradients(zip(grads, [X, W, b]))

    # Log periodically.
    if iter % 20 == 0:
        print(f"Training loss at iteration {iter}: {cost_value:0.1f}")
